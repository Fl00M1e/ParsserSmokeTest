# Алгоритм ParserOnSocial

1. `app.py` запускает Tkinter и один worker Playwright.
2. Worker открывает видимый Chrome с постоянным профилем и страницу ON Social.
3. `sheets.py` подключает выбранную Google Sheets через браузер, читает CSV целевого листа и строит набор пар `social_url + email`.
4. `parser.py` ищет только видимые `Analyze` и `View`, открывает первую найденную карточку и извлекает имя, социальную ссылку и контакты.
5. `dedup.py` нормализует URL и email. Уже существующие пары отбрасываются.
6. Новые строки вставляются одним TSV через clipboard. После вставки тот же диапазон перечитывается; без точного совпадения запись считается неуспешной.
7. После подтверждения кэш пополняется только новыми парами. Список обновляется, затем цикл повторяется.
8. При отсутствии кнопок бот пробует прокрутку/пагинацию, затем `Unlock next` до заданного лимита. STOP прерывает цикл.

Сборки: macOS arm64 и Windows. Подписанные, Intel и другие варианты удалены. Готовые бинарники в репозитории не хранятся; их создаёт GitHub Actions.
